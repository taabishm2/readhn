# HN Reading List – Track Your Monthly Hacker News Reading

[![Live Demo](https://img.shields.io/badge/demo-live-orange)](https://www.readhn.top)
[![GitHub](https://img.shields.io/github/license/taabishm2/readhn)](LICENSE)

A simple, privacy-first reading list for Hacker News. Browse top posts by month, track your reading progress, and sync across browsers—all in a single HTML file with no server required.

## Features

- 📅 **Monthly View** – Browse top Hacker News posts from any month, sorted by points
- ✅ **Reading Tracker** – Mark posts as read, unread, or hide them permanently
- 🎯 **Set Goals** – Choose to read 15, 25, 50, or 100 posts per month
- 🔄 **Cross-Browser Sync** – Sync your progress across devices using your own private GitHub Gist
- 🔒 **Privacy First** – No server, no account, no tracking. Your data stays in your browser
- 📱 **Works Offline** – State persists in localStorage

## Demo

Visit [www.readhn.top](https://www.readhn.top) to try it now—no installation required!

## Usage

1. **Select a month** to view top Hacker News stories
2. **Mark stories** as read with one click
3. **Save favorites** with the heart icon
4. **Optional:** Connect a GitHub token to sync across browsers

## How It Works

HN Reading List uses the [Algolia Hacker News API](https://hn.algolia.com/) to fetch stories. Your reading progress is stored locally and can optionally sync to a private GitHub Gist for cross-browser access.

## Privacy & Data

- All data stored locally in your browser
- Optional GitHub Gist sync uses your own private token
- No server-side tracking or analytics
- No account creation required
